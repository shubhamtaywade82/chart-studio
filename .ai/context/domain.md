# Domain Knowledge

## Exchange APIs
- **DhanHQ**: Uses `dhanhq-node` (internal/custom wrapper). Requires client ID and access token.
- **Binance**: Uses standard REST and WebSocket endpoints for Spot and Futures.

## Internal Concepts
- **Klines/Candles**: OHLCV data.
- **Orderbook**: L2/L3 market depth.
- **OI**: Open Interest for derivatives.
- **Greeks**: Delta, Gamma, Theta, Vega for option chains.
