# Code Review Skill

## Goal
Perform high-quality code reviews focusing on architecture, type safety, and project conventions.

## Workflow
1. Analyze the changes for logic errors.
2. Check for compliance with `coding-standards.md`.
3. Verify that types are correctly used and no `any` is introduced.
4. Ensure that new features are properly integrated into the monorepo structure.
5. Suggest improvements for performance or readability.
